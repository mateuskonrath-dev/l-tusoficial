📊 Core Web Vitals - O Que Medir

Google considera 3 métricas principais para ranking e UX:

LCP - Largest Contentful Paint
Alvo: ≤ 2.5s
Tempo até o maior elemento (hero image, título, etc) aparecer na tela
FID - First Input Delay
Alvo: ≤ 100ms
Tempo de resposta quando o usuário interage (clica em botão, digita, etc)
CLS - Cumulative Layout Shift
Alvo: ≤ 0.1
Quanta a página se move inesperadamente enquanto carrega (estabilidade visual)

🔧 Possíveis Issues & Soluções

⚠️ Se LCP > 2.5s

Hero image demorando para carregar

✓ Verificar tamanho da imagem hero ✓ Usar format WebP + fallback ✓ Adicionar loading="eager" e fetchpriority="high" ✓ Verificar compressão no Vercel

⚠️ Se FID > 100ms

JavaScript bloqueando a thread principal

✓ Verificar tamanho do script.js ✓ Usar defer/async em scripts ✓ Lazy load scripts não essenciais ✓ Otimizar funções CPU-intensivas

⚠️ Se CLS > 0.1

Layout mudando enquanto carrega

✓ Definir width/height em imagens ✓ Reservar espaço para elementos dinâmicos ✓ Evitar inserir conteúdo sem altura definida ✓ Usar CSS container queries

⚠️ Se Score SEO < 95

Problemas com meta tags ou schema

✓ Verificar canonical URL ✓ Validar meta tags ✓ Testar schema.org em Schema.org Validator ✓ Validar robots.txt em Google Search Console
